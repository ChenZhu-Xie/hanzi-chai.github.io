# 视觉第一性原理时空片段标注实验报告：U+7740 着 · J

## 1. 实验背景与范式转移

在字源笔画自动拟合系统的迭代过程中，多次出现“调整启发式规则/局部惩罚项后，补了当前字的东墙，却导致其他字源发生回归（西墙坍塌）”的困境。

为打破算法黑盒调参的死循环，本实验**暂时摈弃现有的启发式组合图搜索与 Chamfer 优化算法**，采用**视觉模型第一性原理（Vision-First Principles）配合被允许的几何工具（直线段、折线段、贝塞尔曲线段）**，对字源进行逐字、逐笔的时空片段（Spatiotemporal Slices）人工标注。通过带划杆的时间切片交互页面，直观呈现每笔的标注思路，并对比现有算法的翻车病灶，为后续重构鲁棒的基座算法提供坚实的 Ground Truth 与反思依据。

首个实验目标：**U+7740 着 · J**（JIS 字源，Glyph ID 900019，单元格索引 30528 J 270）。

---

## 2. 实验过程

1. **底层几何与骨架化提取**：
   - 从 `U4E00.pdf` 第 270 页直接抽取字源闭合外轮廓多边形（Shapely 多边形，52,838 字符 SVG Path）。
   - 执行 256×256 分辨率的形态学骨架化，提取出 1,374 个离散骨架像素点（坐标范围 $x \in [9.4, 89.5], y \in [9.4, 89.8]$）。
2. **纯视觉模型时空序列标注**：
   - 依据汉字笔顺规范与字形结构（IDS: $\text{⿱羊目}$），将全字划分为 12 笔。
   - 严格使用受限几何原语工具（直线段 `L`、折线段 `Polyline`、二次贝塞尔曲线 `Q`）定义各笔控制点。
   - 在 0..100 坐标系内计算各笔画曲线对骨架点云的垂直吸附距离（阈值 2.2px），评估独占认领率与重叠度。
3. **交互式时空划杆页面生成**：
   - 生成单文件独立交互报告 `artifacts/deterministic-decomposer/stroke-annotation-u7740-j.html`。
   - 提供 0..12 步时空滑动杆、自动播放、点云高亮拾取、原语控制柄动态显示与旧算法翻车对照图层。

## 4. 实验结论与核心病灶反思

通过本次视觉模型标注与对照，总结出旧算法导致“补东墙倒西墙”的四大核心机理：

1. **局部距离场的“黑洞引力”陷阱**：
   在 Chamfer 距离场或最近邻贪心搜索中，骨架密集区域（如『目』字 5 笔集中在 $35 \le x \le 74, 52 \le y \le 85$）会形成巨大的低势能场。长撇起点在 $(35.9, 46.9)$，距目左竖仅 $0.5$ 像素，算法受局部势能吸引直接向下扎入目竖，彻底遗弃了 $x \in [10, 36], y \in [47, 78]$ 整个稀疏的真实撇骨架走廊。
2. **切向（Tangent）与全局弦向（Chord）严重脱节**：
   长撇起笔受顿笔影响，前几个像素略有下垂。原算法仅校验起笔前 5 像素的局部切向导数，误认为“合法撇向”，导致一条 99.5% 垂直向下的走廊被误判通过。**必须引入从起笔到收笔的全局宏观弦向角硬约束（$\Delta x \le -20, \Delta y \ge 25$，弦向角 $220^\circ \sim 245^\circ$）**。
3. **跨部件互斥层级（Cross-Leaf Mutual Exclusion）盲区**：
   原算法的路径互斥多停留在“同 Leaf”内，长撇属于 `(0, 1)`，目左竖属于 `(1,)`。因跨偏旁互斥失效，长撇盗占目竖未受到降权打击，导致后续目字拟合时因骨架被毁而产生级联退化。
4. **字形规范源（JIS vs 楷书）模板差异**：
   通用字形模板中羊头上横为短横，而日文字源（J-source）在此处是贯穿全字的大长横。死板套用单一模板 bounding box 会导致正常骨架被错杀为异常残余。
